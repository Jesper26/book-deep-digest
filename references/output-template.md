# 输出结构模板（交付契约）

生成 Markdown 稿时必须严格按此结构，章节标题文字保持一致，便于脚本解析成温习页。
`[...]` 为待填内容，`(...)` 为填写要求。

## 填写硬性要求

- 金句必须用 `>` 引用块，且**第二行以 `—— 位置：` 开头**；释义/重要性用 `**释义**` `**为什么重要**` 开头。
- 自测题的 `答案：` 必须**单独成段**（上一行留空行），否则温习页无法做点击展开。
- 章节标题一律用 `### 第 N 章 · 标题`，生成页面时会自动变成可折叠卡片。
- 全书总结、重点回顾提示等二级标题文字保持与模板一致。
