# 内容质量规则

## 金句（最高优先级规则）

**必须是原文，一字不改；条数不限，宁缺毋滥。** 这两条优先级高于"好不好听""够不够整齐"。

- 能拿到原文（本地文件 / 可检索原文）时：逐字照录，长句可截断，截断处用 `……`，但截断后的片段不得改变原意。
- 拿不到原文、只能凭模型知识时：**只允许写"高置信度名句"**（广为流传、多个来源一致的句子）；没有把握时，改用「观点提炼」并明确标注为转述，格式：

  ```
  > [转述，非原文] 作者的核心主张是……
  > —— 位置：第 N 章（转述，未能核对原文）
  ```

- **禁止**：为了对仗/有力而改写原句；把不同段落的句子拼接成一句；把他人对本书的评论当成作者原话。
- **警惕网络流传"语录"**：读者整理的金句清单、荐书文里的"作者语录"混有大量编造、拼贴、张冠李戴的句子（实测：《我胆小如鼠》的"余华语录"、《你当像鸟飞往你的山》的书名衍生句均为假）。任何金句必须**多来源逐字交叉核对**，能查到页码/章节出处的优先；核不到可靠出处的一律不收，宁留空白也不收假句。

### 金句筛选标准（**数量不限，宁缺毋滥**）

一条句只要满足下面任意一条就收；不满足就不收。**不设上限（某章可以 8 条），也不设下限（某章可以只有 1 条、甚至 0 条）**。
唯一要求是"够格"，不是"够数"——凑数的金句会稀释整份材料的信噪比，比没有更糟。

1. **承载本章核心主张**——抽掉它，本章论点就立不住。
2. **反直觉或与常识冲突**——最值得反复看的部分。
3. **可迁移**——能直接用于工作/生活判断。
4. **定义了关键概念**——不理解它就读不懂后续章节。
5. **给出可执行的判据**——读完后能直接拿来当决策标准用。

不要选：过渡句、纯抒情句、举例中的细节句、需要大段上下文才成立的断章、
以及"换个书名也照样成立"的通用正确的废话。

**收尾自查**：逐条问"如果这本书只能留下 10 句话，它会入选吗？"——答不上来就删掉。

### 释义与"为什么重要"的写法

- **释义**：换一套更直白的话重说，长度与原句相当，不添加原句没有的信息。
- **为什么重要**：指出它支撑的论点或它纠正的错误认知，一到两句。
- 两者都禁止引申到书外、禁止夹带个人评价。

## 章节总结

- 严格对应本章实际内容，**不写"本章讲了……"这类空话开头**。
- "主要论点"用 3 条以内，每条是一个可被反驳的陈述句，而不是名词罗列。
- "关键脉络"用 `A → B → C` 表达作者的推导顺序，体现因果而不是并列。
- "与全书的关联"必须点名具体章节（"承接第 3 章的 X，引出第 7 章的 Y"），否则视为未完成。
- 每章总结控制在 150–300 字。

## 全书总结

- **主线逻辑**必须是"链条"而不是"要点清单"：起点问题 → 中间论证 → 终点结论，中间要出现转折词。
- **核心观点关联**要给出关系类型（前提 / 推论 / 互补 / 约束 / 递进），不能只写"相关"。
- **三个最该记住的结论**要能被独立引用，读完这三句就等于读过这本书的骨架。
- 全书总结不是各章总结的拼接：必须出现章节总结里没有的信息（跨章对照、结构判断、作者意图）。

## 字数与密度

| 项目 | 要求 |
| --- | --- |
| 每章金句 | **不限条数**，按质量标准筛选，宁缺毋滥 |
| 每章总结 | 150–300 字（精简档 ≤100 字） |
| 自测题 | 8–12 道，答案 ≤ 2 句 |
| 全书总结 | 600–1200 字 |
| 全书覆盖 | 章节数 ≤ 20 时逐章；> 20 时按"篇"归并，但鸟瞰表仍列全章节 |

## 禁止事项

- 编造页码、编造不存在的章节、编造原文没有的观点。
- 用"这本书告诉我们……"这类说教口吻；用中性陈述。
- 把评价写成内容（"作者精彩地论证了"→ 直接写论证了什么）。
- 遗漏"存疑处"：只要有任何无法核实的地方，必须在第六节写清楚。
